# Accessibility Standards (WCAG)

## HTML Structure
- Always use semantic HTML — never div/span when a semantic 
  element exists
- Use: <nav>, <header>, <footer>, <main>, <article>, 
  <section>, <aside>

## Text & Images
- All images must have descriptive alt attributes
- Links and buttons must have descriptive text — 
  never "click here"

## Headings
- Use <h1> to <h6> in hierarchical order
- Never skip heading levels

## Keyboard Accessibility
- All interactive elements must be keyboard navigable
- Visible focus indicators required on all focusable elements
