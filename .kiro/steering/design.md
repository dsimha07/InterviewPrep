## Naming Convention 
•⁠  ⁠Meaningful, descriptive names — no unclear abbreviations
•⁠  ⁠PascalCase     → Class names, component names      (AccountController)
•⁠  ⁠camelCase      → Variables, functions, methods      (calculateTotalPrice)
•⁠  ⁠SCREAMING_SNAKE_CASE → Constants, global variables (MAX_QUESTIONS)
•⁠  ⁠kebab-case     → CSS classes, HTML attributes       (background-color)
