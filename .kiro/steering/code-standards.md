# Code Standards

## Comments
- Write comments that are concise, clear, and plain language
- Every function/component must have a comment explaining 
  its purpose
- Keep comments updated when code changes — 
  outdated comments are worse than none
- Include author information in component-level comments

## Formatting & Indentation
- Use Prettier for automated formatting — no exceptions
- Consistent indentation throughout — enforced by Prettier
- Clear visual structure: loops, conditionals, and functions 
  must be properly indented

## Unit Testing
- Tests must be written immediately after functionality 
  is implemented
- A feature is NOT complete until its tests pass
- Test functions, methods, and components individually
